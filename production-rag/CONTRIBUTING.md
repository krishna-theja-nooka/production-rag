# Contributing

Create a branch, explain the problem, make a focused change, and run the test and evaluation
commands in the README. Add regression coverage for changed behavior or a concrete failure.
Avoid committing model weights, secrets, private corpora, or runtime databases.

For retrieval/generation changes, attach before/after evaluation with exact model/configuration
details. Label synthetic data and measured results accurately. Preserve source attribution and
check licenses before adapting third-party code.
